Live API — how it reshapes each screen

A design board of every live-data feature, all frozen at one moment so they read as a single "right now." Visual language: a solid green ✓ = locked at full-time; a pulsing green glow = provisional/live (can still change). Sample data.

07

Provisional-scoring note

Shown wherever live points appear — so nobody panics when stoppage time moves things.

i

Live scoring is provisional

Points and ranks update as goals go in and only lock at full time. A late goal or a VAR call can still change them — your green glow means “leading for now,” a solid ✓ means “done and counted.”
